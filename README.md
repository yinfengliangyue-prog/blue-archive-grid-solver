# 翻格子策略开发部

一个零依赖、浏览器本地运行的矩形物体翻格子求解器。适用于《蔚蓝档案》同类小游戏，也可用于规则相同的寻物类棋盘。

## 使用

直接打开 `index.html`。设置棋盘行列数、每种物体的宽高与**剩余数量**，再用棋盘上方的模式录入：

- `待翻`：尚无信息；
- `已翻空`：确认没有任何剩余物体；
- `已发现`：已显形物体的全部占位。

命中物体后，把该物体的全部格子标成“已发现”，并把对应的剩余数量减 1，再重新计算。

### 快速录入

- **自由画笔**：按住鼠标或手指划过棋盘，连续翻格；
- **框选填充**：拖出矩形，一次把整个区域设为当前状态；
- **框选物品**：用棋盘上的矩形圈出物品占位，自动新增尺寸；已有同尺寸时数量加一；
- **手动框选预设**：在剩余物体栏的 5×5 小网格内拖动，直接创建宽×高尺寸；
- **撤销 / 重做**：支持按钮以及 `Ctrl+Z`、`Ctrl+Shift+Z`；
- **截图识别**：直接粘贴或导入游戏截图。蓝框独立识别右侧棋盘，粉框独立识别左下角物品栏；识别后可校对数量，并用结果整体替换剩余物体清单。识别使用浏览器 Canvas 在本机完成，图片不会上传。

识别器会先搜索规则的 9×5 彩色网格，而不是按固定截图百分比裁切。自动位置不理想时，可在选区内部拖动整体位置，也可以拖动四角或四边的八个白色把手实时缩放。

左下物品栏按卡片逐项识别数量；每张卡片都会在确认区保留为一条独立物品记录。识别后可先校对数量，再整体替换 01 区清单。

截图识别会给出可编辑的初步结果。不同画质、滤镜或游戏皮肤可能影响颜色判断，应用后建议用画笔快速核对和校正。

## 算法

1. 生成每种物体在棋盘上的全部合法横/竖摆放；
2. 组合成互不重叠、且避开已翻空/已发现格的完整布局；
3. 把所有符合证据的完整布局视为等可能，计算每格后验命中概率；
4. 对小状态空间，用 Bellman 递推计算“命中后整件物体显形”规则下的严格最小期望翻数；
5. 完整布局或策略树过大时，自动改用拒绝采样和两步前瞻，并在界面中明确标为近似。

“一次识别格数期望”是点击该格后，因整件物体显形而立即识别的物体格数期望。它适合偏好快速揭示大物体的玩法；真正的全局推荐以“预计剩余翻数”排序。

## 本地测试

项目只使用 Node 内置测试器：

```powershell
node --test solver.test.js
```

## 关键假设

- 物体按格对齐、允许按配置旋转且不能重叠；
- 所有符合当前证据的完整布局等可能；
- 点击命中后，游戏会告知整件物体的准确位置与方向；
- 目标是找到全部剩余物体，并最小化期望点击次数。

若实际游戏的生成器对边缘、方向、物体间距或不同布局设有非均匀权重，需要在布局权重中加入对应先验。
